# Insight 25 MiB iPad隔離検証

基準 main は `e3ace7c2bc0d016ac1b84290a927bdd4f8e6734c`（BUILD 134）。
専用ページの保存データは架空店舗だけです。暗号化前25 MiB・暗号化ファイル36 MiBは、このサーバーが返す検証用モジュールだけに適用します。実店舗のバックアップは使用しないでください。

## 開き方

1. Draft #356のブランチを**新しい専用Codespace**で開きます。
2. リポジトリのルートで `node tests/experiments/ipad-capacity/serve.cjs` を実行します。
3. Ports欄の8075をPrivateとして転送し、同じGitHubアカウントでiPad SafariからHTTPSの転送先を開きます。ホーム画面への追加や通常のInsightのURLはこの検証では使用しません。

## 確認項目

- 画面の1〜8を、日本語主体・英数字主体で各1回行います。最初の大きい暗号化ファイル（約33.34 MiB）と、復元後に保存する小容量ファイルを、iPadの「ファイル」アプリで区別してください。3で選ぶファイルは、その時点の確定版と一致する必要があります。
- 取消後はリビジョンが増えず、復元後は各操作で1増えます。8の再読み込み後は最後のリビジョンとデータの種類が表示されます。Safariでタブを閉じて同じ検証URLを開き直したときも、表示を確認します。
- iPad機種、iPadOS版、各操作の成否、画面の秒数、実際のファイルサイズを記録します。失敗、タブ終了、再読み込みが起きた場合は、操作名とエラー文を控えて止めてください。
- 確認後は専用Codespaceのサーバーを停止します。検証用ダウンロードだけを整理できます。

この画面はIndexedDBと暗号化・バックアップ処理の実機確認用です。本番設定画面の文言やPWAのオフライン起動は対象外です。
